# Recipe Calc

Консольный калькулятор ингредиентов на Java.

## Цель проекта
Создать утилиту для пересчёта пропорций ингредиентов в рецептах.

## Задачи
- Реализовать парсинг входных данных
- Написать логику пересчёта на X персон
- Собрать Maven-проект

## Результат
Консольная утилита: вводите рецепт на N персон → получаете на 1/X персон.

## Стек технологий
- Java, Maven

## Сборка
```bash
mvn clean package
java -jar target/recipe-calc.jar
```
