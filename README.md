# Recipe Calc

Консольный калькулятор ингредиентов на Java. Делит продукты для супа на количество человек.

## Описание

Утилита для расчёта пропорций ингредиентов — вводите рецепт на N персон и получаете на 1/X персон.

## Стек

- Java, Maven

## Сборка

```bash
mvn clean package
java -jar target/recipe-calc.jar
```
